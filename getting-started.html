⚡ 第一步：本地运行

方式1️⃣ - Python（推荐，无需安装）

最简单快速的方式：

python server.py
💡 提示： 浏览器会自动打开。如未打开，访问 http://localhost:8000

方式2️⃣ - Node.js（备选方案）

如果安装了Node.js：

node server.js
💡 提示： 显示网址后，自动打开浏览器
✅ 成功标志：
  • 看到漂亮的首页和各个课程链接
  • 可以点击链接打开各个页面
  • 在手机WiFi中也可以访问

推荐方案：Vercel（最简单）

第1步： 拥有GitHub账户 → https://github.com

第2步： 创建新仓库上传这些文件

第3步： 访问 Vercel → https://vercel.com

第4步： 选择 "New Project" → 选择你的GitHub仓库 → Deploy

⏱️ 等待： 通常1-2分钟后获得网址，如 https://myproject.vercel.app

完成后的效果

  • ✅ 任何人都能访问你的网站
  • ✅ 使用https安全连接
  • ✅ 自动配置CDN加速
  • ✅ 修改文件自动重新部署

📱 在手机上访问（同一WiFi）

步骤

1. 电脑和手机连接同一个WiFi

2. 在电脑的终端运行命令后，会显示：

🌐 局域网访问: http://192.168.1.100:8000

3. 在手机浏览器输入这个地址

💡 注意： 不同WiFi下IP地址可能不同，重新运行server会显示新IP

❓ 常见问题

Q: Python/Node.js运行出错

确保已安装Python 3.6+ 或 Node.js 14+

检查命令：

python --version node --version

Q: 端口8000被占用

修改server.py或server.js中的PORT值，改为8080, 9000等

Q: 浏览器未自动打开

手动访问 http://localhost:8000
